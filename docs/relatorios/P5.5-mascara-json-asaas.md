# Relatório P5.5 — A máscara de segredos do Jev cobre o caso real

## 0. Leitura feita
1. A função `maskSecretsForJev` em `src/core/governance/secret-guard.ts` foi expandida com funções e constantes auxiliares dedicadas (`JEV_ASAAS_KEY_RE`, `JEV_UNQUOTED_ASSIGNMENT_RE`, `collectJevSecretValues`, `maskPlainForJev` e `isJevPlaceholderValue`).

## 3. O que mudou, com `arquivo:linha`

- `src/core/governance/secret-guard.ts:350-353`:
  - Adicionadas constantes privadas `JEV_ASAAS_KEY_RE` (para casar `$aact_[A-Za-z0-9_$:=+\/\-]{16,}`) e `JEV_UNQUOTED_ASSIGNMENT_RE` (para casar chaves comuns sem aspas no valor).
- `src/core/governance/secret-guard.ts:354-358`:
  - Criada a função privada `isJevPlaceholderValue`, que combina `isPlaceholderValue` com reconhecimento de termos como `your_api_key_here`.
- `src/core/governance/secret-guard.ts:360-390`:
  - Criada a função privada `collectJevSecretValues(text, out)`, acumulando candidatos de `findSecretCandidatesInText`, casamentos de `JEV_ASAAS_KEY_RE` e grupos de atribuição sem aspas que passam em `isHighEntropySecretLiteral` e não são placeholders.
- `src/core/governance/secret-guard.ts:392-401`:
  - Criada a função privada `maskPlainForJev(text, found)`, que coleta segredos e realiza a substituição de cada valor por `describeSecretShape(valor)`, ordenando do mais longo para o mais curto.
- `src/core/governance/secret-guard.ts:407-443`:
  - Reescreveu-se `maskSecretsForJev(text)`: analisa se `text` é JSON (objeto ou array); caso afirmativo, faz caminhamento recursivo nos nós string mascarando com `maskPlainForJev`, retornando o JSON re-serializado quando houver segredos (`count: found.size`) ou o texto idêntico byte a byte quando `count: 0`. Para textos planos ou JSON inválido, aplica `maskPlainForJev` diretamente.
- `tests/decision/jev-mascara-segredo-json.test.ts:1-148`:
  - Criada a suíte de testes com 7 cenários cobrindo:
    (a) Atribuição com aspas dentro de JSON;
    (b) `ASAAS_API_KEY=<valor>` com e sem JSON;
    (c) `ASAAS_API_KEY: <valor>` em JSON;
    (d) Chave `$aact_...` crua em texto e dentro de JSON;
    (e) Objeto aninhado com array em JSON;
    (f) Casos que não devem ser mascarados (`your_api_key_here`, `process.env...`, JSON limpo) retornando `count: 0` e texto idêntico;
    (g) Chamada real via `askJevBatch` com `state` JSON contendo atribuição sem aspas, confirmando mascaramento no `body` capturado no fetch espionado.
